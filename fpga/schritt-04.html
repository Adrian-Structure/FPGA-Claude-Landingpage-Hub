4.1 · RTL parametrisiert, eine Takt-Domäne, synchrone Resets

Beweis-Artefakt: rtl/<block>.v

Eine Domäne, synchrone Resets, Parameter statt Magic Numbers — jede Abweichung braucht einen dokumentierten Grund, sonst ist sie ein zukünftiger Geist.

4.2 · Nonblocking-Disziplin (Register <=, Kombinatorik =)

Beweis-Artefakt: Review-Vermerk

Nur Nonblocking macht den Tick-Vergleich reproduzierbar. a=b; b=a; ist KEIN Tausch, sondern undefinierte Reihenfolge.

4.3 · Latchfrei (jede if/case-Kette vollständig)

Beweis-Artefakt: yosys CHECK: 0 Latches

Ein inferiertes Latch simuliert freundlich und geistert auf dem Brett. Jede Kette vollständig, default immer — yosys CHECK ist der Zeuge.

4.4 · Async-Eingänge über 2-FF-Synchronizer (+ Entpreller)

Beweis-Artefakt: Synchronizer-Modul im RTL

Metastabilität ist in der Simulation UNSICHTBAR. Taster und fremde Domänen nur über 2-FF + Entpreller — ein Tastendruck ist nie flankensynchron.

4.5 · Kompiliert sauber

Beweis-Artefakt: iverilog -g2012 Exit 0

Das kleinste Tor — und die wichtigste Demut: RTL_WRITTEN ≠ TB_PASS. Geschriebener Code hat noch nichts bewiesen.
